TenThirty, as an enforcement system

A faithful redesign pass on the onboarding flow and the three post-onboarding tabs. Each screen shows the current build next to a proposed version, with the reasoning below. The goal isn't a new look — it's to make the existing "sleep contract" idea read as firm, calm, and instrument-precise, and to give each screen a single clear focus. Approve what you like; I'll only touch Swift after you sign off.

Current as built today Proposed suggested change bg #0c0807 amber #f0b96b coral (overdue)
Same palette, same fonts — no new type families. Everything below stays inside TenThirty's existing world: Iowan serif for headlines and rule titles, the system sans for everything else, warm amber on near-black. The proposals change hierarchy, structure, and copy, not the typeface. Where the current build feels flat, it's almost always because every element carries equal weight — so the fixes are about deciding what should be loud and what should recede.

What changes & why

  • One rule owns the screen. Today the status card + every rule card share the same size, border and CTA, so nothing tells the eye where to act. The proposed layout makes the next rule a glowing hero node and collapses everything else to slim rail rows — exactly the "current rule should own the screen" intent in your spec.
  • The evening becomes a timeline, not a list. The rules are a timed sequence, so a vertical rail with real times encodes true information: cleared checkpoints tick off behind you, upcoming ones wait ahead. It also removes the repeated-card monotony without losing any rule.
  • Show the apps, not a count. "4 apps selected" is abstract. Naming TikTok / Instagram / YouTube / Reddit on the active card makes the stakes concrete at the moment of the hold.
  • Enforcement state as a one-line strip. A slim ● UNLOCKED · 4 APPS ARMED bar with a status color (green unlocked / amber cooling / coral locked) is faster to read than a full card, and frees vertical space for the hero.
  • Serif for the human voice, sans for the clock. Rule titles in serif (calm); times and counters stay in the system sans but weighted and colored to read as precise. The current header mixes a sans wordmark with the serif used elsewhere — "Tonight" unifies the voice.

The firefly's whole journey lives here. After onboarding, Today shows the coachmark "Earn your first firefly by clearing tonight's sleep rules", which fades as the deck appears. Clear every rule and the firefly rises and roams the Today meadow. Open Trends and that same firefly flies to the calendar cell for the night you earned it. The current screen buries that payoff below a stats grid — so the fireflies land off-screen unless you scroll.

What changes & why

  • The calendar becomes the hero. It's the destination of every earned firefly and the truest proof the contract held — yet today it sits below a 2×2 stat grid, so on first open you see numbers and the fireflies are scrolled out of view. Moving the calendar up top means the migration you just watched on Today actually resolves on screen.
  • Say what a firefly means, right under the grid. New users see glowing dots on dates with no explanation. One line — "each firefly is a night you cleared every rule and kept your apps closed" — turns decoration into proof.
  • Demote the 2×2 grid to a single supporting line. "3 all-clear · 14 opens blocked · 2 late" carries the same numbers without four hero tiles that read like tracking/optimization — the framing your audience pivot moves away from.
  • Insights as calm verdicts, not rankings. "on time 5 of 7" / "late 3 times" state the pattern without "best rule / needs work" language that can read as judgment.
  • Optional: the calendar cells are small (32pt) and the fireflies can overlap the today outline. Slightly larger cells + a hair more row spacing give each firefly room to read as its own light. Renaming the tab to "Proof" is possible but not proposed here — flag if you want it.
