# TenThirty — 10 Reel Scripts (15-second cut)

Tight ~15s versions of the front-loaded scripts (`tenthirty-reel-scripts-frontloaded.md`), keeping the two reference formats:
- **Cats / actionable:** *"explained by cats"* + Kitty narration (steps → App Store CTA).
- **Ducks / relatable:** *@diploma.duck "Routine disruption, explained by ducks"* — cold-open on the feeling, then the fix (neurodivergent-relatable).

Structure per reel: **teaser hook + "Explained by cats" → 2 short Kitty beats → reveal/CTA.**

Production notes:
- **Length:** ~42–50 words each → ~15s at fast TikTok TTS. Drop one beat if your VO runs long.
- **Voice:** flat TikTok-style TTS. Write "ten thirty" not "10:30" for the VO; captions can show **10:30**.
- **Front-loaded hook:** every reel opens on *"There's a free app that…"* — tease first, name last.
- **Reveal/CTA (reuse on all):** *"It's TenThirty — free on the App Store."*
- Caption cues in **bold**.

---
