Design notes

Recommendation: inline card morph (frame 2). On slip tap, cross-fade the hero card body to a compact acknowledgment state in the same card chrome — reuse the amber accent border and LOGGED eyebrow from slipsLogged, but keep copy to two lines max. Hold ~1.4s (or until user scrolls), then collapse to a DoneRailRow with coral “Missed” and spring the next hero up (mirror confirm poof timing, ~0.5s).

Copy (at tap):

  • Eyebrow: “LOGGED” — matches existing full-screen state
  • Headline: “Thanks for being honest.” — warm, non-judgmental (same tone as slipsLogged)
  • Subline: “Apps unlock in 10 min.” — shorter than full-screen; states the consequence without repeating “Habit missed”
  • Optional pill: live countdown “10:00 cooldown” if enforcement timer is already running

When to use full slipsLogged: Keep the existing centered hero replacement only when the slipped item was the last visible checkpoint (queue empty) — no change needed there.

✓ Inline card morph

Feedback stays anchored to the action. No layout jump, no tab-bar overlap. Mirrors hold-to-confirm poof lifecycle. Best when queue has more items.

Toast above tab bar

Easy to implement but easy to miss while scrolling the rail. Competes with mini-player / tab chrome. Feels system-generic, not TenThirty.

Banner under hero

Adds vertical shift and pushes upcoming rows. Duplicates card border weight. Harder to animate cleanly with rail bullet alignment.

Tokens: bg #0c0807, amber #f0b96b, ink #f5e7d7–#5c4f42, missed coral #e89189, card radius 18px, button radius 15px — from LullTheme.swift and HeroRuleCard.
