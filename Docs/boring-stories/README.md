# Boring Story Script Pack

Ten plain-text narration scripts for static boring-story audio generation.

Target delivery:

- Slow bedtime narration, roughly 75-90 words per minute.
- Add gentle sentence pauses during synthesis.
- Avoid dramatic music, sound effects, plot tension, or emotional escalation.
- Export as `m4a` or `mp3` for iOS and Android playback.

At normal audiobook speed these will be shorter than 20 minutes. For the intended Lull experience, synthesize with slow prosody or stretch pacing so each story lands around 20 minutes.
